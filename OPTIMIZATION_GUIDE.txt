优化功能部署指南
==================

## 1. 跳过不必要的等待
✓ 已实现：移除了登录成功后的6秒固定等待
- 登录速度提升约6秒
- 无需额外配置

## 2. 定时批量刷新Cookie（24小时）

### 部署步骤：
```bash
cd /root/minecraft_autologin
chmod +x setup_cookie_refresh.sh
./setup_cookie_refresh.sh
```

### 功能说明：
- 每天凌晨2点自动刷新所有账号的Cookie
- 自动删除密码错误的账号
- 标记Cookie失效的账号
- 日志保存在 cookie_refresh.log

### 手动执行：
```bash
/root/minecraft_autologin/venv/bin/python /root/minecraft_autologin/refresh_cookies.py
```

### 查看日志：
```bash
tail -f /root/minecraft_autologin/cookie_refresh.log
```

## 3. 监控告警

### 部署步骤：
```bash
cd /root/minecraft_autologin
chmod +x setup_monitor.sh
./setup_monitor.sh
```

### 功能说明：
- 每6小时检查一次系统健康状态
- 监控指标：
  * 可用账号数量和比例
  * Cookie有效性
  * 登录成功率
  * 卡密库存
- 自动告警条件：
  * 可用账号 < 20% (严重)
  * 可用账号 < 50% (警告)
  * Cookie失效率 > 30% (严重)
  * 登录成功率 < 50% (严重)
  * 未使用卡密 < 10 (警告)

### 手动执行：
```bash
/root/minecraft_autologin/venv/bin/python /root/minecraft_autologin/monitor.py
```

### 查看日志：
```bash
tail -f /root/minecraft_autologin/monitor.log
```

## 4. 邮件告警系统

### 配置步骤：

#### 1. 生成Gmail应用专用密码
1. 访问 https://myaccount.google.com/security
2. 开启"两步验证"
3. 搜索"应用专用密码"
4. 选择"邮件"和"其他设备"
5. 生成16位密码（无空格）

#### 2. 运行配置脚本
```bash
cd /root/minecraft_autologin
chmod +x setup_email.sh
./setup_email.sh
```

按提示输入：
- 发件人Gmail地址
- 应用专用密码（16位）
- 收件人邮箱（可留空，默认发给自己）

#### 3. 测试邮件
配置完成后会自动发送测试邮件，检查收件箱（可能在垃圾邮件）

### 功能说明：
- 监控告警自动发送邮件
- Cookie刷新完成后发送报告
- 每天早上8点发送每日报告
- 告警级别：
  * INFO（蓝色）：正常信息
  * WARNING（橙色）：警告
  * CRITICAL（红色）：严重

### 告警触发条件：
- 可用账号 < 20%（严重）
- 可用账号 < 50%（警告）
- Cookie失效率 > 30%（严重）
- 登录成功率 < 50%（严重）
- 未使用卡密 < 10（警告）
- Cookie刷新成功率 < 50%（严重）

### 手动发送测试邮件：
```bash
/root/minecraft_autologin/venv/bin/python /root/minecraft_autologin/email_alert.py "测试标题" "测试内容" "info"
```

### 故障排查：
如果收不到邮件：
1. 检查应用专用密码是否正确（16位，无空格）
2. 确认已开启两步验证
3. 检查网络能否访问 smtp.gmail.com:587
4. 查看垃圾邮件文件夹
5. 检查 .env 文件中的配置

### 禁用邮件告警：
如果不需要邮件告警，系统会自动降级为仅控制台输出，无需额外配置。
